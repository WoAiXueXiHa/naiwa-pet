# 当前采用的跑步及过渡姿势

以用户指定的 final.gif 第0帧为唯一角色身份依据，使用内置 imagegen 生成实际姿势，不使用旧模糊 run.gif。

- run-left：8张整体协调跑步姿势，包含摆臂、对侧腿迈步和身体起伏。
- start：6张抱肚站立到放开手臂起跑的姿势。
- turn：6张从左向右、经过正面、带小步换重心的转身姿势。
- relax-accepted：只保留原收尾条的第4、5、6张。用户拒绝的前三张眯眼歪笑姿势未保存到此处，也未用于任何起笑或收尾动作。

`scripts/build_pose_bridges.py` 无参数运行即可从这些已选素材重建当前过渡和跑步。动作开始、结束使用精确的原始端点；停步会先完成当前步幅。原始侧目使用GIF的真实回转帧收尾。重影明显的光流实验已废弃，不在当前运行素材中。

生成提示摘要：

- 跑步：保持黄色奶蛙的绿色侧眼、大白肚皮、深色手脚和3D材质，左右手臂与对侧腿交替摆动，膝盖回收时弯曲，身体轻微起伏，完整身体与统一尺度。
- 起跑：手从肚皮松开，屈膝、前倾、转移重心、抬脚、迈步，依次衔接到已选跑步姿势。
- 转身：左侧三分之二视角逐步经过正面到右侧，头部先转、肩膀腹部随后，小步换重心。
- 收尾：闭嘴、睁眼、放松肩膀，双手回到腹前，温和恢复站姿；剔除用户指定的三张表情。
