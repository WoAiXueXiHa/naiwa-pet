# 隐私与本地数据

- 程序仅通过 Codex 客户端附带的后台服务读取账号和额度，不读取、复制或提交认证文件。登录及账号切换在客户端中完成，奶蛙不提供单独登录入口。服务遵循客户端使用的 CODEX_HOME，不切换到独立 CLI 或其它账号目录。
- 界面只显示账号首字符与遮罩，隐藏邮箱域名。提醒去重使用账号摘要；摘要并非绝对匿名，配置仍应作为私人数据保护。
- `%APPDATA%/naiwa-desktop/settings.json` 保存偏好、窗口坐标、暂停状态和去重键。损坏备份及临时文件也应同等保护。
- 不保存原始协议日志。服务端错误使用固定提示，其它应用错误展示前脱敏；系统工具与第三方依赖日志不在此保证范围内。
- 测试截图及结果在 artifacts，默认不提交。真实额度诊断包含自己的额度数值，不宜公开分享。
- 源码迁移不会迁移账号。删除用户数据前退出程序，删除后恢复默认设置。
- 不包含遥测或项目自建上传服务；安装依赖、下载 Electron、登录和查询额度需要相应网络连接。
