# 健壮性审查与迁移记录

审查日期：2026-10-26。基线版本 1.1.1，原始 TypeScript 检查及 8 项规则测试通过。C 盘原件保留，E 盘为后续开发目录；原常驻程序及启动快捷方式未替换。

## 修复与边界

| 原问题 | 处理 | 验证 |
| --- | --- | --- |
| 配置直接覆盖，损坏后静默恢复 | 临时文件写入后原子替换；损坏文件保留副本；写入失败固定诊断 | 损坏 JSON、非法字段、往返保存、目录写入失败 |
| 旧配置坐标及去重记录无约束 | 有限坐标、暂停时间和记录类型校验，记录数量上限 | 配置测试及窗口几何测试 |
| IPC 未检查调用窗口与 frame | 仅允许应用拥有窗口的主 frame；参数保持白名单 | 外部 sender、子 frame、空 frame、非法设置 |
| 协议空值可能引起读取异常 | 忽略非法 JSON 和非对象消息；固定服务错误提示 | 模拟 stdout、并发启动、超时、断连、关闭清理 |
| 额度窗口可能包含 Infinity 或错误结构 | 校验有限值与结构，无有效窗口时保留旧快照 | 畸形额度输入测试 |
| 素材清单和加载失败缺少处理 | 校验路径、尺寸、时长和眼睛区域；核心帧缺失提示，过渡失败跳过 | 清单越界及缺失测试，打包素材完整性检查 |
| 生命周期与职责集中 | 拆出存储、IPC、调度器、窗口几何；清理定时器和监听 | 调度器启停测试与打包回归 |
| 邮箱域名、路径和内部标识暴露 | 集中脱敏，公开快照去掉 accountId，诊断不输出程序路径 | 脱敏测试及提交文件扫描 |

## 剩余限制

2026-10-27 启动与连接分离：Windows 登录任务无条件启动奶蛙；desktop-monitor.ts 独立检测客户端会话，未打开时不连接额度服务，退出时停止后台服务并标注旧数据。关闭后返回的旧请求结果通过会话检查丢弃，重新打开自动刷新。22 项自动测试及 16 项模拟打包检查通过，包含关闭客户端时桌宠保留及重新打开自动连接的场景。真实客户端检测和额度打包检查另行验证；未强制重启正在使用的 Codex 或 Windows。

2026-10-27 启动恢复修复：发现监测任务退出码 0xC000013A，桌面识别正常，但仅有登录触发器无法恢复已终止任务。新增每分钟恢复触发器，沿用 IgnoreNew 防重复；进程枚举瞬态异常在循环内处理。实测停止计划任务并退出奶蛙后，无人工启动，由下一次分钟触发自动恢复任务并启动奶蛙。任务被禁用、未登录或设备睡眠等系统状态仍不保证即时启动。

气泡位置修复：气泡底边固定在奶蛙画布上方 16 像素，额外透明空间容纳提醒，长内容在气泡内部滚动。扩展窗口时保留脚底基准；旧配置通过 windowLayoutVersion 一次性迁移，避免重启后位置漂移。20 项自动测试通过，新增尺寸 40/80/160/360 下气泡不重叠的打包检查；屏幕边缘测试改为相对脚底位置，避免把新增透明留白误认为角色可见区域。

客户端单来源改动：移除 npm、独立安装和 PATH 中的 CLI 查找回退，只定位客户端附带服务；移除登录按钮、preload 登录接口及主进程登录处理。登录和切换账号交由客户端，每次刷新重新建立后台服务连接以重新加载共享登录状态。19 项自动测试通过，包含独立 CLI 存在时仍拒绝选用的场景；真实账号额度读取和打包检查通过。此实现读取客户端同一 CODEX_HOME 下的登录状态，不抓取界面，也不能跨自定义数据目录推断当前客户端账号；相关限制已写入 README。

额度与面板后续修复：复现了只在 Codex 注入 PATH 时能找到 CLI 的问题，加入桌面安装目录发现后，在使用系统/用户 PATH 的环境中真实额度读取成功。18 项自动测试和 13 项真实额度打包检查通过，截图确认面板正常显示两个额度窗口。原先空白面板未单独稳定复现；新增加载提示、失败重试、刷新异常恢复及渲染进程退出后的重载。置顶改为 screen-saver 层级，启动和缩放均应用；不覆盖系统安全桌面。

后续联动启动修复：旧版本监测进程未运行，且仅匹配 Codex 后台 CLI，无法准确识别商店版桌面会话。现改为当前用户计划任务管理生命周期，并识别 OpenAI.Codex 包内的 ChatGPT.exe，以进程 ID 与启动时间区分会话。已验证本机桌面识别、计划任务运行及奶蛙实际启动；没有为了验证而强制重启正在使用的 Codex。

未进行长期运行压力测试，也未覆盖所有物理多屏、混合 DPI、显卡和系统通知策略。文件替换依赖操作系统文件系统语义，不宣称断电级持久性；备份失败仍会回退默认值。自动额度验证使用模拟数据，不证明所有未来 Codex 协议版本兼容。

模块重组保留主进程的窗口、托盘和通知编排，没有引入插件框架。素材缺失和故障测试覆盖有限，仍需结合用户实际机器回归。素材来源说明不等同于版权授权。
